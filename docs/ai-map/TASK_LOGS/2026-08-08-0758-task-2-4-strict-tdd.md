**Mechanism notes (reproduced from environment):**
- `structuredClone(new Proxy({}, {}))` → throws `DataCloneError` in jsdom/Node V8; removing the
  `try { structuredClone(value) } catch { return null }` call from `materializeRecord` causes Proxy
  to pass through, giving `true` instead of `false`.
- A plain object with an accessor getter in `details` passes `cloneDetails` without the
  `hasNoAccessorInGraph` scan, so `appendAudit` incorrectly returns `true`.
- A cyclic object passes `structuredClone` in Node 22 (which handles cycles), so the `JSON.stringify`
  gate is necessary to correctly reject it; removing it causes `appendAudit` to return `true`.
